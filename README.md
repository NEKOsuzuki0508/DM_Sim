# デュエマ SAOオリカ シミュレーター

`index.html`、`styles.css`、`app.js`、`effects.js`を同じフォルダーに置き、`index.html`をブラウザーで開くと、1人分のデッキだけで始められるローカル対戦を始められます。追加インストールは不要です。

## できること

- 添付カード資料から収録したカード（横線で区切られた両面カードを統合）を使った自分用40枚デッキ作成
- 自分用の最大8枚の超次元ゾーン設定
- 5枚のシールドと5枚の初期手札を使った対戦開始
- シールドゾーンをクリックして自分のシールドをブレイクし、S・トリガーも解決
- ターン、ドロー、マナチャージ、カード使用、召喚、攻撃、ブロック、シールドブレイク
- 登場時能力、SAOマップ、2モード呪文、メクレイドなどカード固有効果の自動解決
- G・ゼロ、A.I.L.4、F.L.A.、革命0トリガーのコスト・誘発処理
- ドラグハートの条件付き装備（同条件の複数枚も装備可能）と装備先への能力付与、装備先が場を離れた時の超次元への返却
- クリックで開く超次元カード一覧
- S・トリガーの宣言、山札切れとダイレクトアタックによる勝敗判定
- 局面のブラウザー内保存と再開

## 操作の流れ

1. 「デッキを編集して開始」を選び、自分のメインデッキを40枚にします。相手のターンはなく、相手側は攻撃や効果の対象として扱います。自分の超次元カードは8枚まで追加できます。
2. あなたのターンのみを進めます。画面上部の「次のステップ」で進行を手動スキップできます。ターン開始とドローは自動処理します。マナを置いた後、使えるカードがなければメインステップから攻撃ステップへ自動で進み、攻撃ステップには毎ターン入ります。攻撃できるクリーチャーがいれば操作待ちになり、攻撃しない場合は「次のステップ」または「次のターン」で進めます。手札や攻撃などプレイヤーが選べる行動がある場合は、その場で待機します。
3. マナステップに手札を1枚マナへ置き、メインステップに使用可能なマナをタップしてカードを使用します。自分のシールドはシールドゾーンをクリックしてブレイクできます。
4. 攻撃ステップでクリーチャーを選んで攻撃します。ブロッカーがある場合は防御側が選べます。
5. 両面カードは手札または超次元ゾーンで選び、使う面のボタンを押します。SPRシノンは手札からクリーチャー面・呪文面のどちらでも使えます。シノンがバトルゾーンにいる場合、攻撃時に「幻影の一弾」を唱えるにはスマッシュ・バーストを使います。攻撃可能なクリーチャーがいる間は攻撃ステップに留まります。

## 画面配置

盤面はバトルゾーンを上段、シールド・マナ・各山札を中段、手札を下段に配置します。画面全体の横スクロールを抑え、カードが多いゾーン内だけ横に閲覧できます。

## ルールの扱い

ゲーム開始時のデッキ枚数、同名カード上限、初期シールド、先攻の初回ドローなし、通常のターン進行、基本的な攻撃と勝敗判定は、添付PDF「デュエル・マスターズ総合ゲームルール Ver.1.54」に合わせています。

SPRシノンは手札から呪文面を通常使用できます。クリーチャー面でバトルゾーンにいる時は、攻撃時のスマッシュ・バーストで呪文面を唱えられ、唱えた後もシノンはバトルゾーンに残ります。ドラグハートは横線で区切られた表裏を1枚として登録しています。能力の多くは自動解決し、対象やモードを選ぶ必要がある時はダイアログを表示します。能力処理の同時誘発順、複雑な置換効果、例外的なカード相互作用は簡略化しています。
